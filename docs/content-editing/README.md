# Content editing guide

This guide explains how to update the ESN Ukraine website with **Sanity Studio**. You do not need any programming knowledge.

**Audience:** ESN Ukraine volunteers who publish news, events and other content. The Studio interface is in Ukrainian; this guide quotes its labels in **bold**, with an English explanation.

## What you can change yourself

| You can change in the Studio | Ask a developer to change |
|---|---|
| News articles | Menus, footer and social media links |
| Events | Texts on the homepage, such as "This is ESN Ukraine" |
| The big slider at the top of the homepage (**Spotlight**) | The About Us, Erasmus+, ESNcard and Contact pages |
| Photos in the "Our Network" block on the homepage | The Privacy Policy and Cookie Policy |
| National Board members | The map of sections |
| Former boards | The year in the board group headings, for example "The Board 2025-26" |
| ESN sections | Pages marked "under construction" |

For changes in the right column, contact the webmaster (see [Getting help](#getting-help)).

## Getting access

1. Open the Studio at **<https://esnukraine.org/studio>**.
2. Log in with your Sanity account. You need an **invitation** to the ESN Ukraine project, which the webmaster can send.
3. Log in with the same method (Google, GitHub or email and password) that matches the invited email address.

## How publishing works

1. **Create or edit** a document. The Studio saves your changes automatically as a **draft**. Drafts are not visible on the website.
2. Fix any **red error messages**. The Studio does not publish a document while a required field is empty or a rule is broken, for example an image that is too large.
3. Click **Publish**. The document is now live.
4. The website updates **automatically within a few seconds**. If you still see the old version, wait a moment and refresh the page once more. In rare cases it can take up to an hour.

To change published content, edit it and click **Publish** again.

To take content offline, open the document's menu (**⋯**):

- **Unpublish** removes the document from the website but keeps it in the Studio;
- **Delete** removes it completely.

To undo a mistake, open the document's **history**, find the earlier version and restore it.

## Golden rules

- **Keep at least one item in Spotlight.** The homepage slider is built from news items and events with Spotlight switched on. If none is switched on, the homepage stops working.
- **Compress photos before uploading,** and stay within the size limits. See [Images and files](images-and-files.md).
- **Describe images** in the alternative text fields (**Alt текст**). Visitors who use screen readers depend on them.
- **Do not change the link (slug) of something already published.** Links that people have shared would stop working.
- **Write slugs with Latin letters, numbers and hyphens only.** See [Slugs](images-and-files.md#slugs).
- **Everything you type may become public.** This includes fields that are not displayed, such as a board member's email.
- **Remove registration links** from events once registration has closed.
- **Do not delete all events or all board members.** The website would then show built-in example content.
- **Check the result** on the website after publishing, on a computer and on a phone.

## Getting help

For technical problems, write to **<web-master@esnukraine.org>**. Please include:

- the link to the page or the name of the document;
- what you did and what you expected to happen;
- a screenshot of any error message.

Developers can find technical background in [Troubleshooting](../guides/troubleshooting.md).
